# PDF Problembook Cutter

두 단 PDF에서 필요한 문제를 골라 풀이 공간이 있는 A4 문제집으로 재배치하는 웹앱입니다. PDF 읽기, 화면 표시, 자르기, 결과 생성은 모두 브라우저 안에서 처리되며 원본 파일은 서버로 전송되지 않습니다.

## 기능

- 홀수·짝수 페이지별 좌·중앙·우 경계선 슬라이더 및 드래그/터치 설정
- `Start`, `Continue`, `End` 경계로 여러 단·페이지에 걸친 문제 연결
- 경계선 추가, 드래그 이동, 삭제 모드, 실행취소와 키보드 단축키
- 원본 PDF 목차를 이용한 빠른 페이지 이동
- 문제별 풀이 공간 및 줄 표시 설정
- 출력 제목과 문제 번호 표시 선택
- 원본 정답 페이지를 결과 PDF 뒤에 부록으로 첨부
- 작업 상태 JSON 저장 및 같은 PDF에서 복원
- 데스크톱, 태블릿, 모바일 대응

## 개발 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다.

## 검증

```bash
npm run check
```

개별 명령은 `npm run lint`, `npm test`, `npm run build`입니다.

## 배포

정적 데이터 저장소나 별도 API가 필요하지 않습니다. 기본 구성은 OpenAI Sites 및 Cloudflare Workers와 호환되며, 빌드 결과는 브라우저에서 PDF를 처리하는 형태로 배포됩니다.

## 사용 흐름

1. 원본 PDF를 불러옵니다.
2. 홀수·짝수 페이지의 좌·중앙·우 세로선을 마우스나 터치로 끌어 맞춥니다.
3. 문제 시작에 `S`, 다음 단으로 이어질 지점에 `C`, 문제 끝에 `E`를 표시합니다. 삭제 모드를 켜고 선을 누르면 삭제됩니다.
4. 제목·문제 번호·풀이 공간·정답 부록을 설정한 뒤 결과 PDF를 내려받습니다.

연속된 `S`는 같은 위치에서 앞 문제를 닫고 새 문제를 시작합니다. `C`로 닫힌 조각은 다음 읽기 순서의 단 맨 위부터 같은 문제로 이어집니다.

문제 자르기 화면에서는 `S`, `C`, `E`, `X`를 도구 선택에, `←`, `→`를 페이지 이동에, `Ctrl/⌘ + Z`를 실행취소에 사용할 수 있습니다.

## 개인정보와 제한

- 파일은 브라우저 메모리에서만 처리됩니다.
- 암호로 잠긴 PDF는 먼저 암호를 해제해야 합니다.
- 매우 큰 스캔 PDF는 기기 메모리에 따라 처리 시간이 길어질 수 있습니다.
